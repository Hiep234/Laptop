## CHƯƠNG 5: GIẢI THÍCH CÁC CÔNG NGHỆ SỬ DỤNG

### 5.1. Python

Python là ngôn ngữ lập trình bậc cao, dễ đọc và dễ viết. Trong project này, Python được sử dụng để:
- Viết toàn bộ mã nguồn backend (phía server).
- Xử lý logic nghiệp vụ: tìm kiếm, chấm điểm, phân loại ý định.
- Giao tiếp với database MySQL và API của Google Gemini.
- Xử lý ngôn ngữ tự nhiên tiếng Việt (sửa lỗi chính tả, trích xuất từ khóa).

Python được chọn vì cú pháp đơn giản, hệ sinh thái thư viện phong phú, và là ngôn ngữ phổ biến nhất trong lĩnh vực AI/Machine Learning.

### 5.2. Flask

Flask là một framework web nhẹ của Python, giúp tạo ứng dụng web và API nhanh chóng. Trong project này, Flask đảm nhiệm:
- **Tạo REST API**: Định nghĩa các đường dẫn (endpoint) như `/api/chat`, `/api/health`.
- **Xử lý HTTP request/response**: Nhận dữ liệu từ frontend (JSON), xử lý, và trả kết quả về.
- **Middleware**: Tích hợp CORS (cho phép gọi API từ domain khác), Rate Limiter (giới hạn request chống spam).

Flask được chọn vì nhẹ, linh hoạt, dễ học, phù hợp cho project quy mô vừa và nhỏ.

### 5.3. API là gì?

API (Application Programming Interface) là **cầu nối** giữa frontend (giao diện) và backend (xử lý logic). Trong project này:
- Frontend gửi tin nhắn của người dùng đến API endpoint `/api/chat`.
- Backend xử lý, gọi AI, tìm kiếm sản phẩm rồi trả kết quả về qua API.
- Dữ liệu trao đổi theo định dạng **JSON** – một chuẩn phổ biến để truyền dữ liệu trên web.

Ví dụ gửi request:
```json
{
  "message": "Laptop gaming dưới 20 triệu",
  "session_id": "abc-123"
}
```

Ví dụ nhận response:
```json
{
  "session_id": "abc-123",
  "message": "Chào bạn! Với ngân sách dưới 20 triệu cho gaming...",
  "intent": "search",
  "tags": ["USE:gaming"],
  "budget": {"min": 0, "max": 20000000},
  "product_ids": [12, 45, 78]
}
```

### 5.4. AI Model – Google Gemini

AI Model (mô hình trí tuệ nhân tạo) là "bộ não" giúp chatbot hiểu câu hỏi và tạo câu trả lời tự nhiên. Project sử dụng **Google Gemini** – mô hình ngôn ngữ lớn (LLM) của Google.

Vai trò của Gemini trong hệ thống:
- **Sinh câu trả lời**: Nhận thông tin sản phẩm + câu hỏi, viết phản hồi tự nhiên bằng tiếng Việt.
- **Phân loại ý định**: Khi hệ thống keyword không chắc chắn, Gemini giúp xác định người dùng muốn gì.
- **Tư vấn thông minh**: So sánh sản phẩm, giải thích trade-off, đưa ra lời khuyên phù hợp.

Gemini **không trực tiếp truy cập database**. Hệ thống tìm kiếm sản phẩm trước, rồi gửi thông tin cho Gemini để viết câu trả lời. Kỹ thuật này gọi là **RAG (Retrieval-Augmented Generation)**.

### 5.5. NLP – Xử lý ngôn ngữ tự nhiên

NLP (Natural Language Processing) là lĩnh vực giúp máy tính hiểu ngôn ngữ con người. Trong project, NLP được áp dụng qua:

| Kỹ thuật | Ví dụ | File thực hiện |
|----------|-------|----------------|
| Sửa lỗi chính tả | "loptop" → "laptop" | `nlp_utils.py` |
| Bỏ dấu tiếng Việt | "tư vấn" → "tu van" | `nlp_utils.py` |
| Trích xuất từ khóa | "laptop gaming rẻ" → USE:gaming, PRICE:cheap | `synonym_map.py` |
| Phân tích ngân sách | "dưới 20 củ" → (0, 20.000.000) | `budget_parser.py` |
| Fuzzy matching | "assu" → "asus" | `nlp_utils.py` |
| Nhận diện thực thể | "MacBook Air" → entity | `entity_extractor.py` |
| Phân loại ý định | "so sánh Dell và HP" → compare | `intent_router.py` |

### 5.6. Database – MySQL

Database là nơi lưu trữ toàn bộ dữ liệu có cấu trúc. Project sử dụng **MySQL**. Dữ liệu bao gồm:
- **Thông tin sản phẩm**: Tên, CPU, RAM, GPU, giá, tồn kho, màu sắc…
- **Đánh giá khách hàng**: Rating (1–5 sao), bình luận.
- **Đơn hàng**: Lịch sử mua hàng của từng người dùng.
- **Mã giảm giá**: Mã code, phần trăm giảm, ngày hết hạn, số lượng còn lại.
- **Lịch sử xem**: Sản phẩm nào người dùng đã xem, xem bao nhiêu lần.

Hệ thống sử dụng **SQLAlchemy** (ORM) để tương tác với MySQL bằng code Python thay vì viết SQL thủ công.

## CHƯƠNG 6: CÁCH SỬ DỤNG HỆ THỐNG

### 6.1. Sử dụng qua API

**Gửi tin nhắn chat:**
```
POST http://localhost:5000/api/chat
Body: { "message": "Tư vấn laptop cho sinh viên", "session_id": "..." }
```

**Tiếp tục hội thoại** (gửi cùng session_id):
```
POST http://localhost:5000/api/chat
Body: { "message": "Con nào nhẹ nhất?", "session_id": "uuid-session" }
```

**Gợi ý theo hành vi:**
```
GET http://localhost:5000/api/recommendations?user_id=123
```

**Xóa lịch sử:**
```
POST http://localhost:5000/api/chat/clear
Body: { "session_id": "uuid-session" }
```

### 6.2. Các loại câu hỏi chatbot hỗ trợ

| Loại câu hỏi | Ví dụ |
|--------------|-------|
| Tư vấn theo nhu cầu | "Laptop gaming dưới 25 triệu" |
| Tư vấn theo ngân sách | "Laptop tầm 15–20tr cho sinh viên" |
| So sánh sản phẩm | "So sánh Dell với ASUS tầm 20tr" |
| Follow-up | "Con nào nhẹ hơn?", "Cái đầu giá bao nhiêu?" |
| Hỏi kiến thức | "IPS hay OLED tốt hơn?" |
| Chào hỏi | "Xin chào", "Hello" |
| Tiếng lóng | "Loptop gamming re ma tot" → Hệ thống tự sửa |

## CHƯƠNG 7: MỘT SỐ LỖI THƯỜNG GẶP VÀ CÁCH KHẮC PHỤC

### 7.1. Thiếu thư viện Python

| | Chi tiết |
|---|---------|
| **Biểu hiện** | `ModuleNotFoundError: No module named 'flask'` |
| **Nguyên nhân** | Chưa cài thư viện hoặc chưa kích hoạt venv |
| **Khắc phục** | `venv\Scripts\activate` rồi `pip install flask flask-cors flask-sqlalchemy flask-limiter google-generativeai python-dotenv pymysql` |

### 7.2. Sai API Key Gemini

| | Chi tiết |
|---|---------|
| **Biểu hiện** | *"⚠️ Lỗi API Key Gemini. Kiểm tra lại GEMINI_API_KEY."* |
| **Nguyên nhân** | API Key trong `.env` bị sai hoặc hết hạn |
| **Khắc phục** | Tạo key mới tại [Google AI Studio](https://aistudio.google.com/apikey), cập nhật vào `.env` |

### 7.3. Không chạy được server

| | Chi tiết |
|---|---------|
| **Biểu hiện** | `ValueError: DB_URI environment variable is required` |
| **Nguyên nhân** | Thiếu file `.env` hoặc thiếu biến `DB_URI` |
| **Khắc phục** | Tạo file `.env` đầy đủ (xem Chương 4, Bước 5) |

### 7.4. Port bị trùng

| | Chi tiết |
|---|---------|
| **Biểu hiện** | `OSError: Address already in use` |
| **Nguyên nhân** | Cổng 5000 đang bị ứng dụng khác chiếm |
| **Khắc phục** | Tắt ứng dụng đang dùng port 5000, hoặc đổi port trong `index.py`: `app.run(port=5001)` |

### 7.5. Lỗi kết nối Database

| | Chi tiết |
|---|---------|
| **Biểu hiện** | `OperationalError: Can't connect to MySQL server` |
| **Nguyên nhân** | MySQL chưa khởi động hoặc thông tin kết nối sai |
| **Khắc phục** | Khởi động MySQL; kiểm tra `DB_URI` trong `.env` |

### 7.6. Hết quota Gemini API

| | Chi tiết |
|---|---------|
| **Biểu hiện** | *"⚠️ Hết quota Gemini API. Vui lòng thử lại sau vài phút nhé!"* |
| **Nguyên nhân** | Vượt giới hạn request miễn phí |
| **Khắc phục** | Chờ vài phút (quota reset tự động); hoặc nâng cấp gói trả phí |

### 7.7. Model không tồn tại

| | Chi tiết |
|---|---------|
| **Biểu hiện** | *"⚠️ Model 'xxx' không tồn tại."* |
| **Nguyên nhân** | Tên model trong `.env` bị sai hoặc đã ngừng hỗ trợ |
| **Khắc phục** | Đổi `GEMINI_MODEL` thành `gemini-2.5-flash` hoặc `gemma-3-4b-it` |

## CHƯƠNG 8: KẾT LUẬN

Hệ thống AI Chatbot tư vấn laptop (CSCV – LaptopBot) đã được xây dựng thành công với khả năng **tự động tư vấn, tìm kiếm và gợi ý sản phẩm laptop** phù hợp với nhu cầu và ngân sách của từng khách hàng. Chatbot giao tiếp bằng tiếng Việt tự nhiên, hỗ trợ sửa lỗi chính tả, nhận diện tiếng lóng, và ghi nhớ ngữ cảnh hội thoại — mang lại trải nghiệm tư vấn gần giống con người.

Việc hiểu rõ cấu trúc project giúp lập trình viên dễ dàng **bảo trì, nâng cấp và mở rộng** hệ thống trong tương lai. Mỗi module được thiết kế theo nguyên tắc **phân tách trách nhiệm**: file xử lý NLP tách riêng khỏi file tìm kiếm, file chấm điểm tách riêng khỏi file gọi AI — giúp sửa lỗi hoặc thêm tính năng mới mà không ảnh hưởng đến các phần khác.

Sự kết hợp giữa **Python, Flask, Google Gemini AI và MySQL** tạo nên một hệ thống chatbot thông minh, có khả năng mở rộng cao. Trong tương lai, hệ thống có thể được phát triển thêm:
- Tích hợp giao diện chat realtime với WebSocket.
- Hỗ trợ đa ngôn ngữ (tiếng Anh, tiếng Nhật…).
- Thêm khả năng nhận diện hình ảnh sản phẩm.
- Huấn luyện mô hình AI riêng dựa trên dữ liệu tư vấn thực tế.
- Tích hợp chatbot vào ứng dụng di động.

Đồ án đã chứng minh rằng việc ứng dụng trí tuệ nhân tạo vào lĩnh vực thương mại điện tử là hoàn toàn khả thi, giúp nâng cao chất lượng dịch vụ khách hàng và tối ưu hóa quy trình bán hàng.
