## CHƯƠNG 1: GIỚI THIỆU TỔNG QUAN HỆ THỐNG

### 1.1. Hệ thống AI Chatbot là gì?

Hệ thống AI Chatbot tư vấn laptop (tên nội bộ: **CSCV – LaptopBot**) là một ứng dụng trí tuệ nhân tạo có khả năng giao tiếp tự động với người dùng bằng ngôn ngữ tự nhiên tiếng Việt. Chatbot đóng vai trò như một nhân viên tư vấn ảo, giúp khách hàng tìm kiếm và lựa chọn laptop phù hợp với nhu cầu và ngân sách cá nhân.

Thay vì người dùng phải tự lọc hàng trăm sản phẩm trên website, chatbot sẽ **hỏi – hiểu – gợi ý** giống như một tư vấn viên thực thụ.

### 1.2. Mục đích của chatbot

- **Tự động hóa tư vấn**: Giảm tải cho nhân viên bán hàng, hỗ trợ khách hàng 24/7.
- **Cá nhân hóa gợi ý**: Dựa trên nhu cầu, ngân sách và lịch sử mua hàng của từng người dùng để đưa ra sản phẩm phù hợp nhất.
- **Nâng cao trải nghiệm mua sắm**: Giúp khách hàng ra quyết định nhanh hơn thông qua so sánh, đánh giá sản phẩm.

### 1.3. Chatbot có thể làm được gì?

| STT | Chức năng | Mô tả |
|-----|-----------|-------|
| 1 | Tư vấn laptop theo nhu cầu | Người dùng mô tả nhu cầu (gaming, văn phòng, đồ hoạ, lập trình…), chatbot gợi ý 3–5 sản phẩm phù hợp |
| 2 | Tìm kiếm theo ngân sách | Hỗ trợ nhiều cách nói: "dưới 20 triệu", "tầm 15–25tr", "giá sinh viên"… |
| 3 | So sánh sản phẩm | So sánh chi tiết 2 hoặc nhiều laptop, trình bày dạng bảng |
| 4 | Gợi ý theo hành vi mua hàng | Dựa vào giỏ hàng và lịch sử xem sản phẩm để đề xuất laptop tương tự |
| 5 | Tự sửa lỗi chính tả tiếng Việt | Nhận diện và sửa lỗi gõ sai: "loptop" → "laptop", "gamming" → "gaming" |
| 6 | Nhận diện đối tượng người dùng | Tự phát hiện người dùng là sinh viên, game thủ, dân thiết kế hay lập trình viên |
| 7 | Hiển thị đánh giá & mã giảm giá | Trích xuất review thực tế và mã khuyến mãi đang có từ database |
| 8 | Ghi nhớ ngữ cảnh hội thoại | Nhớ câu hỏi trước đó để trả lời follow-up mà không cần nhắc lại |

### 1.4. Công nghệ sử dụng

| Công nghệ | Vai trò trong hệ thống |
|------------|----------------------|
| **Python 3.x** | Ngôn ngữ lập trình chính để xây dựng toàn bộ backend |
| **Flask** | Framework web tạo REST API, xử lý HTTP request/response |
| **Google Gemini API** | Mô hình AI sinh câu trả lời tự nhiên, thông minh |
| **MySQL** | Cơ sở dữ liệu lưu trữ sản phẩm, đơn hàng, đánh giá, mã giảm giá |
| **SQLAlchemy** | Thư viện ORM giúp tương tác với database bằng code Python |
| **Flask-CORS** | Cho phép frontend gọi API từ domain khác |
| **Flask-Limiter** | Giới hạn số request để bảo vệ server khỏi spam |
| **python-dotenv** | Quản lý biến môi trường (API Key, kết nối database) |

## CHƯƠNG 2: CẤU TRÚC THƯ MỤC PROJECT

### 2.1. Sơ đồ tổng quan

```
CSCV/
│
├── index.py                  ← File khởi chạy server (entry point)
├── config.py                 ← Cấu hình hệ thống (database, API key, Flask)
├── routes.py                 ← Định tuyến API và xử lý logic chat chính
├── models.py                 ← Định nghĩa cấu trúc các bảng trong database
│
├── gemini_service.py         ← Kết nối và giao tiếp với AI Gemini
├── conversation.py           ← Quản lý bộ nhớ hội thoại
├── intent_router.py          ← Phân loại ý định người dùng
├── entity_extractor.py       ← Nhận diện thông tin chi tiết từ câu hỏi
│
├── search.py                 ← Tìm kiếm sản phẩm thông minh
├── scoring.py                ← Chấm điểm và xếp hạng sản phẩm
├── recommender.py            ← Gợi ý sản phẩm theo hành vi người dùng
├── product_intelligence.py   ← Khai thác review, mã giảm giá, độ phổ biến
│
├── nlp_utils.py              ← Công cụ xử lý ngôn ngữ tiếng Việt
├── budget_parser.py          ← Phân tích ngân sách từ câu nói tự nhiên
├── synonym_map.py            ← Từ điển đồng nghĩa và sửa lỗi chính tả
│
├── test_ai.py                ← File kiểm thử chatbot

└── venv/                     ← Môi trường ảo Python (thư viện cài đặt)
```

### 2.2. Giải thích chi tiết từng file

#### 2.2.1. Nhóm file khởi chạy và cấu hình

**`index.py`** – File khởi chạy server

Đây là file chạy đầu tiên khi khởi động hệ thống. Nó khởi tạo Flask server, đăng ký tất cả API endpoints, và chạy ứng dụng trên cổng 5000. Khi chạy lệnh `python index.py`, server sẽ khởi động và sẵn sàng nhận request.

**`config.py`** – Cấu hình hệ thống

Đọc các thông tin cấu hình từ file `.env` (API Key, đường dẫn database…). Khởi tạo Flask app, kết nối database, cấu hình rate limiter. Quản lý session người dùng (tạo mới, dọn dẹp session hết hạn tự động mỗi 5 phút).

**`.env`** – Biến môi trường

Lưu trữ các thông tin nhạy cảm: mật khẩu database, API Key của Gemini. File này **không được đẩy lên Git** để bảo mật. Ví dụ nội dung:

```
DB_URI=mysql+pymysql://root:123456@localhost:3306/laptop_store
GEMINI_API_KEY=AIzaSy...
GEMINI_MODEL=gemma-3-4b-it
TOP_K=5
```

#### 2.2.2. Nhóm file API và xử lý logic

**`routes.py`** – Định tuyến API và xử lý chat

Đây là file quan trọng nhất, chứa toàn bộ logic xử lý tin nhắn từ người dùng. Định nghĩa 5 API endpoints:

| API Endpoint | Phương thức | Chức năng |
|-------------|-------------|-----------|
| `/api/chat` | POST | Gửi tin nhắn và nhận phản hồi từ chatbot |
| `/api/chat/clear` | POST | Xóa lịch sử hội thoại |
| `/api/chat/tags` | POST | Xem các tags đã nhận diện từ cuộc trò chuyện |
| `/api/recommendations` | GET | Gợi ý laptop theo hành vi mua hàng |
| `/api/health` | GET | Kiểm tra trạng thái hoạt động của server |

**`models.py`** – Định nghĩa cấu trúc database

Mô tả các bảng dữ liệu trong MySQL dưới dạng class Python (sử dụng ORM). Các bảng chính:

| Bảng | Chức năng |
|------|-----------|
| `products` | Thông tin sản phẩm laptop (tên, mô tả, thương hiệu) |
| `product_options` | Cấu hình chi tiết (CPU, RAM, GPU, giá, màn hình…) |
| `product_variants` | Phiên bản màu sắc, tồn kho, giá chênh lệch |
| `product_reviews` | Đánh giá của khách hàng (rating, bình luận) |
| `brands` | Danh sách thương hiệu (ASUS, Dell, HP…) |
| `orders` / `order_items` | Đơn hàng và chi tiết đơn hàng |
| `cart_items` | Giỏ hàng của người dùng |
| `discounts` | Mã giảm giá |
| `user_view_history` | Lịch sử xem sản phẩm |

#### 2.2.3. Nhóm file AI và xử lý ngôn ngữ

**`gemini_service.py`** – Giao tiếp với AI Gemini

Chứa **system prompt** (bộ chỉ dẫn) hướng dẫn AI cách trả lời: phong cách thân thiện, gợi ý sản phẩm có trong kho, so sánh bằng bảng… Xây dựng context sản phẩm (thông số, giá, tồn kho, review) để gửi kèm câu hỏi cho AI. Hỗ trợ ghi nhớ hội thoại giúp AI nhớ ngữ cảnh.

**`intent_router.py`** – Phân loại ý định người dùng

Xác định người dùng muốn làm gì: tìm laptop, so sánh, hỏi chi tiết, chào hỏi, hay hỏi ngoài chủ đề. Sử dụng phương pháp **hybrid**: ưu tiên nhận diện bằng từ khóa (nhanh), nếu mơ hồ thì dùng AI Gemini phân loại (chính xác). Các loại ý định: `search`, `compare`, `detail`, `followup`, `greeting`, `thanks`, `general`, `off_topic`.

**`entity_extractor.py`** – Nhận diện thực thể

Trích xuất tên sản phẩm cụ thể người dùng nhắc đến (ví dụ: "MacBook Air", "ASUS ROG"). Phát hiện phân khúc người dùng: sinh viên, game thủ, dân thiết kế, lập trình viên… Tính điểm giá trị sản phẩm (value score).

**`conversation.py`** – Quản lý bộ nhớ hội thoại

Lưu trữ lịch sử tin nhắn qua lại giữa người dùng và chatbot (tối đa 10 lượt). Theo dõi sở thích người dùng: thương hiệu quan tâm, nhu cầu sử dụng, ngân sách, sản phẩm đã từ chối. Tự động tóm tắt cuộc trò chuyện cũ để tiết kiệm bộ nhớ.

#### 2.2.4. Nhóm file tìm kiếm và gợi ý

**`search.py`** – Tìm kiếm sản phẩm thông minh

Nhận câu hỏi đã xử lý, truy vấn database để tìm sản phẩm phù hợp. Áp dụng bộ lọc: ngân sách, thương hiệu, CPU, kích thước màn hình. Có cơ chế fallback: nếu không tìm thấy, tự động nới lỏng điều kiện. Đảm bảo đa dạng kết quả.

**`scoring.py`** – Chấm điểm và xếp hạng sản phẩm

Chấm điểm từng sản phẩm dựa trên hơn 10 tiêu chí: nhu cầu sử dụng, ngân sách, thông số kỹ thuật, tồn kho, đánh giá khách hàng… Chứa bảng xếp hạng hiệu năng CPU và GPU.

**`recommender.py`** – Gợi ý theo hành vi

Phân tích giỏ hàng và lịch sử xem sản phẩm. Tính độ tương đồng giữa sản phẩm đã xem và sản phẩm trong kho. Loại bỏ trùng lặp.

**`product_intelligence.py`** – Khai thác dữ liệu sản phẩm

Tổng hợp đánh giá khách hàng, lấy mã giảm giá đang hoạt động, thống kê sản phẩm bán chạy. Sử dụng cache để tối ưu hiệu suất.

#### 2.2.5. Nhóm file hỗ trợ NLP

**`nlp_utils.py`** – Xử lý ngôn ngữ tiếng Việt

Chuẩn hóa văn bản (bỏ dấu, chuyển thường), sửa lỗi chính tả, trích xuất tags, hỗ trợ fuzzy matching.

**`budget_parser.py`** – Phân tích ngân sách

Hiểu nhiều cách nói về giá: "dưới 20tr", "tầm 15–25 triệu", "giá sinh viên", "20 củ"… Chuyển đổi số viết bằng chữ. Nhận diện ngân sách mặc định.

**`synonym_map.py`** – Từ điển đồng nghĩa và sửa lỗi

Chứa hơn 300 từ/cụm từ đồng nghĩa tiếng Việt ánh xạ sang tag chuẩn. Hỗ trợ tiếng lóng Gen-Z và từ điển sửa lỗi chính tả.

## CHƯƠNG 3: LUỒNG HOẠT ĐỘNG CỦA CHATBOT

### 3.1. Sơ đồ tổng quan

```
Người dùng nhập câu hỏi
        │
        ▼
┌─────────────────────────┐
│  Frontend gửi POST      │  POST /api/chat
│  request đến API         │  { "message": "...", "session_id": "..." }
└─────────────────────────┘
        │
        ▼
┌─────────────────────────┐
│  Sửa lỗi chính tả       │  "loptop gamming" → "laptop gaming"
│  (nlp_utils.py)          │
└─────────────────────────┘
        │
        ▼
┌─────────────────────────┐
│  Phân loại ý định        │  search / compare / greeting / followup...
│  (intent_router.py)      │
└─────────────────────────┘
        │
        ▼
┌─────────────────────────┐
│  Trích xuất thông tin    │  Tags: USE:gaming, BRAND:asus
│  + Phân tích ngân sách   │  Budget: dưới 25 triệu
└─────────────────────────┘
        │
        ▼
┌─────────────────────────┐
│  Tìm kiếm + Chấm điểm  │  Truy vấn DB → lọc → score → rank
│  (search.py + scoring.py)│
└─────────────────────────┘
        │
        ▼
┌─────────────────────────┐
│  AI Gemini tạo câu       │  Input: câu hỏi + sản phẩm + lịch sử
│  trả lời tự nhiên        │  Output: phản hồi tiếng Việt
└─────────────────────────┘
        │
        ▼
┌─────────────────────────┐
│  Trả kết quả JSON        │  { "message": "...", "product_ids": [...] }
│  về cho frontend          │
└─────────────────────────┘
        │
        ▼
  Hiển thị trên giao diện
```

### 3.2. Giải thích chi tiết từng bước

**Bước 1: Người dùng nhập câu hỏi**

Người dùng gõ câu hỏi bằng tiếng Việt tự nhiên, ví dụ: *"Tư vấn laptop gaming dưới 25 triệu"*.

**Bước 2: Frontend gửi request**

Giao diện web gửi yêu cầu HTTP (POST) đến `/api/chat` của backend, kèm theo nội dung tin nhắn và mã phiên (session_id).

**Bước 3: Sửa lỗi chính tả**

Hệ thống tự động kiểm tra và sửa lỗi gõ sai phổ biến. Ví dụ: "loptop" → "laptop", "gamming" → "gaming".

**Bước 4: Phân loại ý định**

Hệ thống xác định người dùng muốn gì:
- **search**: Muốn tìm/tư vấn laptop → Tiến hành tìm kiếm.
- **compare**: Muốn so sánh → Lập bảng so sánh.
- **greeting**: Chào hỏi → Trả lời chào và giới thiệu.
- **followup**: Hỏi tiếp → Sử dụng kết quả trước đó.

**Bước 5: Trích xuất thông tin**

Phân tích câu hỏi để lấy ra: nhu cầu (gaming), thương hiệu, ngân sách (dưới 25 triệu), thông số yêu cầu.

**Bước 6: Tìm kiếm và chấm điểm**

Truy vấn database, lọc sản phẩm theo điều kiện, chấm điểm từng sản phẩm. Sản phẩm điểm cao nhất được chọn gửi cho AI.

**Bước 7: AI Gemini tạo câu trả lời**

Gửi cho AI: câu hỏi + thông tin 5 sản phẩm + lịch sử chat. AI tổng hợp và viết câu trả lời tự nhiên, thân thiện.

**Bước 8: Trả kết quả**

Server trả về JSON chứa câu trả lời, loại ý định, danh sách sản phẩm. Frontend hiển thị lên giao diện.

## CHƯƠNG 4: CÁCH CÀI ĐẶT VÀ CHẠY PROJECT

### 4.1. Yêu cầu hệ thống

| Yêu cầu | Phiên bản tối thiểu |
|----------|---------------------|
| Python | 3.8 trở lên |
| MySQL | 5.7 trở lên |
| RAM | 4GB trở lên |
| Kết nối Internet | Cần thiết (để gọi Gemini API) |

### 4.2. Hướng dẫn từng bước

**Bước 1: Cài đặt Python**

Tải Python từ [python.org](https://python.org). Lưu ý đánh dấu **"Add Python to PATH"**.

```bash
python --version
```

**Bước 2: Cài đặt MySQL**

Tạo database:

```sql
CREATE DATABASE laptop_store CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

**Bước 3: Tạo môi trường ảo**

```bash
python -m venv venv
```

Kích hoạt:
- Windows: `venv\Scripts\activate`
- macOS/Linux: `source venv/bin/activate`

**Bước 4: Cài đặt thư viện**

```bash
pip install flask flask-cors flask-sqlalchemy flask-limiter
pip install google-generativeai python-dotenv pymysql
```

**Bước 5: Cấu hình file `.env`**

```env
DB_URI=mysql+pymysql://root:123456@localhost:3306/laptop_store
GEMINI_API_KEY=your_api_key_here
GEMINI_MODEL=gemma-3-4b-it
TOP_K=5
CANDIDATE_LIMIT=500
SESSION_TTL=3600
```

> Lấy API Key tại: https://aistudio.google.com/apikey

**Bước 6: Import dữ liệu**

```bash
mysql -u root -p laptop_store < data.sql
```

**Bước 7: Chạy server**

```bash
python index.py
```

Kết quả khi chạy thành công:

```
LAPTOP AI CHATBOT - REST API
  DB : localhost:3306/laptop_store
  AI : Google Gemini (gemma-3-4b-it)
  API: http://localhost:5000
```

**Bước 8: Kiểm tra**

Truy cập `http://localhost:5000/api/health`. Nếu thấy `"status": "ok"` là server hoạt động bình thường.
